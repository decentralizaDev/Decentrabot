# DecentraBot — Página de enlaces

Tu link-in-bio personal: enlaces a tus redes y cursos de YouTube.

## Ver la página en tu computadora

Doble clic en `index.html` — se abre en tu navegador. Eso es todo.

> Los 4 archivos deben estar siempre juntos en la misma carpeta:
> `index.html`, `styles.css`, `perfil.jpg`, `README.md`

## Editar contenido

- **Cambiar textos o enlaces:** abre `index.html` con el Bloc de notas
  (o VS Code) y edita lo que está entre las etiquetas.
- **Añadir otro botón de red:** copia un bloque `<a class="boton">...</a>`
  completo y pégalo debajo, cambiando el `href` y el texto.
- **Añadir otro curso:** copia un bloque `<a class="curso">...</a>`.
- **Cambiar colores:** abre `styles.css` y edita las variables de la
  sección `:root` (arriba del todo).

## Publicarla gratis en internet (GitHub Pages)

1. Crea una cuenta en https://github.com
2. Crea un repositorio nuevo llamado `decentrabot` (público)
3. Sube los 4 archivos (Add file → Upload files)
4. Ve a Settings → Pages → Source: elige la rama `main` y carpeta `/ (root)`
5. Guarda. En 1-2 minutos tu página estará en:
   `https://TU-USUARIO.github.io/decentrabot/`

Después podrás comprar un dominio propio (tipo decentrabot.com) y
conectarlo, pero para empezar el de GitHub está perfecto.
